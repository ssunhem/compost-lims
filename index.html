Module 3: In-Process Monitoring & Turning Schedule (ติดตามการหมัก 18 วัน)

ตารางงานอัตโนมัติ 18 วัน หน้าจอบันทึกผลแบบ Touch-friendly สำหรับมือถือหน้างาน และระบบวินิจฉัยปัญหาอัตโนมัติ (FR-PROC-01 ถึง FR-PROC-03)

Module 4: Compost Quality & Crop Bioassay Testing (ตรวจคุณภาพปุ๋ยและปลูกพืช)

บันทึกผลวิเคราะห์ทางเคมีกายภาพหลัง Day 18 (NPK, OM, C:N, EC) และผลการทดลองปลูกพืช (FR-TEST-01, FR-TEST-02)

1. บันทึกผลวิเคราะห์คุณภาพปุ๋ยหมักหลัง Day 18 (FR-TEST-01) เปิดกว้าง (Optional Chemical Fields)
หมายเหตุการตรวจวัด: ค่าทางเคมีและเครื่องมือชั้นสูง (C, N, P, K, OM, EC) ไม่จำเป็นต้องกรอกครบทุกช่อง สามารถเว้นว่างเฉพาะค่าที่ไม่มีเครื่องมือวัด และบันทึกเฉพาะภาพถ่ายหรือลักษณะทางกายภาพได้
บันทึกภาพความละเอียดและสีของปุ๋ยหมักเมื่อสิ้นสุดกระบวนการ
ตารางผลวิเคราะห์คุณภาพปุ๋ยหมักที่บันทึกแล้ว
2. บันทึกผลการทดลองปลูกพืช (Crop Bioassay - FR-TEST-02)
ถ่ายภาพเปรียบเทียบความสูงและใบของพืชในแปลงทดลอง
ตารางผลการทดลองปลูกพืช (Crop Bioassay Records)

Module 5: Analytics & Hypothesis Testing (วิเคราะห์ผลและพิสูจน์สมมติฐาน)

เปรียบเทียบกราฟอุณหภูมิ 18 วัน (Temperature Profile) ความสัมพันธ์ระหว่าง C:N Ratio สารตั้งต้น กับอัตราการเติบโตของพืช และส่งออกรายงาน PDF / CSV (FR-ANA-01 ถึง FR-ANA-03)

กราฟเส้นเปรียบเทียบอุณหภูมิแกนกลาง 18 วัน (Temperature Profile Across Batches - FR-ANA-01) เป้าหมายช่วง Thermophilic: 55–65°C
แดชบอร์ดเปรียบเทียบ C:N Ratio สารตั้งต้น กับ อัตราการเติบโตของพืช (FR-ANA-02)

Module 6: ระบบสำรองข้อมูล, Audit Log และสถาปัตยกรรมฟรี (Offline / NFR 4.3)

รองรับการทำงานแบบ Offline/Online บน PC และ Android พร้อมระบบสำรองข้อมูลและบันทึกประวัติการแก้ไขย้อนหลัง (Audit Log)

สำรองและกู้คืนข้อมูลในเครื่อง (Automated Local Backup & JSON Sync - NFR 4.3)

ข้อมูลทั้งหมดถูกบันทึกอัตโนมัติลงในฐานข้อมูลภายในเบราว์เซอร์ (IndexedDB และ LocalStorage) ทำให้ใช้งานขณะไม่มีอินเทอร์เน็ตที่หน้าแปลงหมักได้ทันที และสามารถคัดลอก/นำเข้าข้อมูล JSON เพื่อย้ายเครื่องระหว่างมือถือ Android และ PC ได้ฟรีโดยไม่ต้องพึ่งเซิร์ฟเวอร์เสียค่าใช้จ่าย

สถาปัตยกรรมฟรีสำหรับใช้งานจริงบน PC / Android (Zero-Cost Stack)
  • Client & Offline Engine (ฟรี 100%): HTML5 + Vanilla JS + IndexedDB / LocalStorage ทำงานบน Chrome/Edge (PC) และ Chrome บน Android ได้โดยไม่ต้องติดตั้งโปรแกรมเสริม
  • Web Hosting ฟรี: อัปโหลดไฟล์ index.html ไฟล์เดียวขึ้น GitHub Pages, Cloudflare Pages หรือ Netlify Free Tier เพื่อเปิดผ่าน HTTPS และติดตั้งเป็น PWA (Add to Home Screen บน Android)
  • Database Sync: ใช้ฟังก์ชัน Export/Import JSON หรือเชื่อมต่อ Supabase Free Tier (PostgreSQL 500MB ฟรี) เมื่อต้องการซิงค์หลายอุปกรณ์
ประวัติการแก้ไขข้อมูลอุณหภูมิและสูตรปุ๋ยย้อนหลัง (Audit Log - NFR 4.3) 0 รายการ
ส่งออกข้อมูลรายงานการทดลอง (FR-ANA-03)

คุณสามารถคัดลอกข้อมูล CSV ด้านล่างเพื่อวางใน Excel / Google Sheets ได้ทันที (หรือเมื่อดาวน์โหลดแอปไปรันนอกโหมดพรีวิว จะสามารถบันทึกเป็นไฟล์ลงเครื่องได้โดยตรง)

📡 ตั้งค่าการเชื่อมต่ออุปกรณ์ IoT ผ่านโปรโตคอล MQTT (ขนานกับการกรอกมือ)

เชื่อมต่อเซนเซอร์วัดความชื้น อุณหภูมิ และเครื่องชั่งน้ำหนักดิจิทัลผ่าน MQTT over WebSockets เพื่อดึงค่าเข้าสู่ฟอร์มอัตโนมัติ หรือเลือกกรอกตัวเลขด้วยมือได้ทุกช่องตามความสะดวก
